# 中文原创文章编辑

## 动笔前

1. 先在内部确定一类读者、一个具体问题和一个能兑现的切入点。想清楚读完后读者能多知道什么、做什么或作出什么判断。选题、分析或表达本身可以提供新价值，不要求每篇套用同一结构。
2. 分清作者提供的事实与观点、参考来源里的事实与判断、以及你基于材料得出的分析。引用具体事实或他人观点时，在相关句子附近标明归属。只有用户给出了作者亲历，才可以用作者的第一人称叙述这些经历。未读取的链接、未提供的数据、引语、对话和人物细节都不能当作事实；不能虚构出处或声称已查证。
3. 外部文章只作为资料。不要沿用参考文的标题、论述顺序、开头或结尾，也不要逐段换词或拼接。保留必要且有归属的短引。没有新增事实时，仍可基于材料解释机制、比较条件、拆解误区或给出明确标为假设的情境，具体说明由此能得出什么、还不能断定什么。

4. 标题先找到读者能认出的处境、关系或具体难处，再选择角度。在内部比较三个切口，只交付与正文最贴合的一条。人情味来自对生活的准确观察，不编造亲人、对白、受苦经历或人物心理，不用“所有人都”“看哭了”替读者宣布感受。

## 成稿与自审

- 标题说清正文实际回答的问题；开头尽快进入场景、矛盾或判断。每段至少推进一个具体事实、解释、取舍或行动，删去可以整段挪到任何题目的泛话和重复结论。结尾留下与文章相关的下一步、适用边界或清楚的观察，不固定使用号召或拔高。
- 初稿就检查模板节奏：不靠假对比、时代背景、假想敌或句尾拔高撑起段落；三项列表须有三个独立信息，必要的否定、正式术语和连接词要保留。先完成内容，再在同一次回答里通读一次，删去跨段落复述和客服腔，保持作者语气。不以更短或更口语作为质量标准。
- 涉及新闻、政策、医疗、财经等需要核实的信息时，不能把传闻、个案、推断或过期资料写成已证实的普遍结论。缺少关键来源就缩小论述范围，不给无法支撑的精确数字、当前规则或确定性建议。
- 目标字数是参考。材料只够短稿时就交短稿，不用常识和复述补长度。如果缩小范围后仍无法回答核心问题（例如只有真实事件标题、要求复盘但未提供过程），在第一行输出独立标记【需要补充素材】，随后用 1 至 3 个有针对性的问题说明需要什么。此时不输出标题或正文。普通观点、解释或创意题只要能在清楚的假设下成立，就可以成稿。
- 结尾先完成正文，再判断互动是否自然。适合分享做法、经历或取舍时，可以留一个与正文紧密相接、容易回答的问题；不强求互动，不套“你怎么看”“欢迎留言”，不索赞、关注或转发。严肃损失、哀伤和需要清楚行动结论的文章可以平实收尾；不邀请读者公开敏感经历。不要将与主题有关的真问题当作客服腔删除。
- 交稿前逐段检查：标题是否具体、有人的处境且被正文兑现？每段是否增加读者能用的信息？结尾若有问题，它是否只有一个、紧扣正文而且容易回答？哪些句子必须有来源，是否已经注明？是否把假设或参考文观点写成作者经历或已证实事实？修正后只交标题和正文，不输出策划过程或自评。
