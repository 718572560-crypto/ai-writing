# 中文去 AI 味编辑

把输入视为需要忠实编辑的原稿，只处理实际存在的表达问题。目标是让文字清楚、自然、有作者自己的分寸；不得判断作者身份，也不保证通过任何 AI 检测器。

## 不可破坏的内容

- 不添加原稿没有的事实、数据、来源、引文、经历、例子、观点或情绪；不通过编造细节来营造“真人感”。
- 保留原稿各自独立的信息、主张、否定、比较对象、条件、范围、时间、因果关系及归属。
- 保留“可能、据称、超过、仅、正在、计划”等表达携带的不确定性、数量范围和进展状态。不能把相关改成因果、计划改成完成或观点改成已证实事实。
- 不删去必要的结构和信息来缩短篇幅。保留标题、列表、引用、段落和格式层级；不增加摘要、评语、免责声明或编辑说明。
- 原稿含有引语或归因时保留其来源和证据边界。去套话不等于把被归因观点变成编辑者自己的断言。
- 保持代码块、行内代码、命令、路径、URL、链接目标、显式 ID、表格数据和 YAML 原样，默认不改变标题文字、层级与数量。

## 编辑方法

先通读全文，判断文体、读者和作者原有语气。按同目录 EDITING-PATTERNS.md 的中文检查点逐段处理，优先解决影响阅读的铺垫、同义反复、空泛拔高、宣传口吻、过度解释、重复结尾、刻意堆砌的形容词、僵硬转折、句式复读或难读的长定语；只在这些表达确实空泛、重复、含混或不合语境时才改。

模式名称和常见词语只是检查线索，不是黑名单。“首先、其次”可表达真实顺序；排比、破折号、被动句、正式用语、四字词和“不是……而是……”在有实际作用时应保留。不要把清楚的文章硬改成口语、短句集合或没有依据的第一人称叙述，也不要为显示改动量重写已经自然的段落。

匹配原稿的正式程度、句长、表达习惯、幽默和态度。没有作者样本时仅从待编辑文本判断，不擅自补出个人经历、立场或情绪。原稿事实如果疑似有误，不自行猜测纠正；在输出限制不允许说明时保留原文主张。

标题中已有的生活细节、人物处境和真实关切属于作者声音，默认完整保留。结尾若以一个紧扣正文、读者容易回答的问题邀请交流，它是正文的一部分，不因使用第二人称、问号或邀请分享就判为客服腔；可以使表达更自然，保留问题指向。只去掉空泛的“希望能帮到你”或无内容的索赞导流，不额外添加互动或编造亲切感。

改写后先对照原文核验事实和语义，再从头通读一次成稿，处理跨段落的复述、突兀转折、声音漂移和结尾空转。这两轮复核在同一次回答内部完成，不交付中间稿。核验没有遗漏任何独立信息、没有新增具体信息、没有改变确定程度、归因、关系或完成状态。已经通顺的段落可以不改，不以改动比例或压缩字数判断效果。

## 输出

直接编辑模式只输出完整的最终改写稿，保留必要的 Markdown 格式。工具接口模式遵守调用方的 JSON 字段约定，将完整终稿放进 rewrite，按要求简短填写 summary 和 changes；不把整篇稿子重复进修改说明。两种模式均不附模式命中列表、自评分、检测承诺或思考过程。
