# 有术 Studio · 创作工作室

GitHub 项目：**AI 写作**（私有仓库 `ai-writing`）。本地开发、上传及服务器更新流程见 [GITHUB_DEPLOYMENT.md](GITHUB_DEPLOYMENT.md)。

根据 qdaiyoushu.com 的公开前端功能分析，独立设计、独立编写的新网站。纸感配色、墨绿主色、原创 SVG 插画，兼容电脑与手机。动态文章读取使用 playwright-core 和本机 Edge / Chrome。

## 启动

安装 Node.js 24.15 或更新的 24.x LTS 版本（亦支持 22.22.2+ 的 22.x 或 26+），在本目录运行：

```powershell
npm install
npm start
```

浏览器打开 http://127.0.0.1:4175 。双击 `启动网站.cmd` 也可以启动，它会在首次启动时安装依赖；默认通过守护进程运行，异常退出或连续健康检查失败会自动恢复；同一端口禁止重复启动，连续崩溃会停止重启并记录原因。关闭该终端将停止服务。当前机器已安装所需依赖和 Edge。

## 已实现

- 创作首页：快捷工具、分类选题、最近作品、创作指南。
- 写作工作台：文章、大纲、标题、润色、去 AI 味五种模式；平台、风格与目标字数设置。
- 去 AI 味编辑：按项目内 `skills/humanizer-zh/SKILL.md` 的中文编辑规范调用已配置模型，清理空话、重复、模板节奏和机械表达；严格保留原文事实、限定、归因、结构与作者声音，不承诺绕过任何 AI 检测。
- 文章链接识别：粘贴公开网站的 HTTP / HTTPS 文章链接，自动读取真实标题、作者、正文（保留头条 / 公众号专用适配）并写入可编辑输入框，支持手动读取和展开全文。无需 AI 密钥。
- 稿纸编辑器：编辑标题、正文、实时字数、自动保存、手动保存、复制、Markdown 导出。
- 灵感文章库：聚合公开平台热点并整理成新选题，支持分类、搜索、阅读、收藏和以主题开始构思。
- 创作记录：作品搜索、重新编辑、字数统计、导出与移除。
- 全局搜索：同时查询作品和文章库内容，快捷键 Ctrl/Cmd+K。
- 备份：JSON 导入、导出；导入时合并，保留同 ID 的已有作品；未保存稿纸也包含在备份中。
- 页面无外部字体、图片或 CDN 依赖。

## 文章链接读取

公开页面优先用 HTTP 读取，提取特定正文容器；头条等动态网页按需使用独立的无登录浏览器上下文渲染后再取文。默认查找本机已安装的 Edge / Chrome / Chromium，其他位置可在 `.env` 设置 `BROWSER_EXECUTABLE=浏览器可执行文件绝对路径`。

支持 `mp.weixin.qq.com/s/…`、公众号 `/s?__biz=…` 长链接、头条 `/article/…`、`/a…`、`/i…`、`/w/…` 和 `/is/…` 分享地址。成功以实际正文为准；不把整页导航、推荐、评论或错误信息当作文章。链接只允许指定平台，重定向和浏览器子资源也检查目标，拒绝内网地址；单页上限 6 MB，写作框上限 20,000 字。

实际验证：用户提供的头条文章 `7702399938851832339` 识别到作者“八道宴之”及 3433 字正文；公众号公开教程 `0zdiDQ9L3R7t_4N6V2jqcw` 识别到作者“AI有术”及 886 字正文。已逐项核对文章标题、首段及末段。文本提取不包含图片中的文字；本文内容超过限制时会截取并提示。

## 文章库每日热点更新

文章库每天按北京时间上午 08:00 刷新公开平台的当日热点。服务进程会每分钟检查刷新时点；如果电脑或服务当时关闭，重启后会自动补做当天刷新。要按时更新，部署环境需要保持服务运行。页面会显示最近一次成功刷新时间、当前列表缓存时间，以及各公开源本次是否可用；上游暂时失败时优先显示已有缓存。

热点只作为选题线索：文章库保留来源标题、简短摘要和原文链接，并生成新的灵感摘要、写作角度和提示，不复制整篇文章。发布前仍应打开来源核实事实。头条等平台聚合依赖其公开接口可访问性，不能保证每个时段都有数据。微信公众号没有默认可稳定抓取的公开文章流；如需加入公众号相关内容，须在 `.env` 配置可公开访问的 RSS、Atom 或 JSON 订阅地址。

可选订阅源配置示例（JSON 数组，最多 20 项）：

```env
ARTICLE_LIBRARY_TIMEZONE=Asia/Shanghai
ARTICLE_LIBRARY_FEEDS=[{"name":"公开资讯源","url":"https://example.com/feed.xml"}]
```

支持 RSS / Atom XML 和 JSON Feed；每项需提供唯一名称及 HTTPS 订阅地址。RSS 的条目和 JSON Feed 的 `items` / `articles` 项应含标题、原文链接，可附简短摘要、发布时间和分类。来源状态会显示在文章库页面。订阅源拉取失败时会保留其上次成功数据；配置错误或订阅源无法公开访问时不会被当作已接入。

## 两种运行方式

### 无模型密钥：本地构思

网站可直接运行。主题会填入规则模板，提供结构框架、标题句式或原文编辑检查清单。页面明确标记“本地构思”，不会把规则模板称为 AI 正文，不消耗外部服务。

### 真实 AI：OpenAI / 中转服务

打开写作页的「配置服务 ↗」，填写以下信息后点击「保存配置」，无需重启：

1. API 基础地址：官方为 https://api.openai.com/v1；中转填写服务商提供的 HTTPS 地址（通常包含 /v1）。支持粘贴完整 /responses 或 /chat/completions 地址，程序会整理为基础地址；裸域名自动添加 /v1。
2. API Key：官方或中转提供的密钥。密钥仅保存到本机服务端 ai-config.json，不回传浏览器、不写入作品备份。该文件是明文配置，请勿分享或提交版本库；源码压缩包不包含它。同一地址留空可保留原密钥，换地址必须重新输入，避免将旧密钥发送给另一家服务商。
3. 默认模型：可点选预设，也可点击「拉取服务商模型列表」，或手动输入中转模型别名。写作页可以为每次生成单独选择模型。
4. 接口协议：自动模式下官方使用 Responses，中转使用 Chat Completions；中转支持 Responses 时可以手动切换。程序不会失败后重复发起另一种付费生成。
5. 兼容设置：Chat 默认 max_completion_tokens，旧中转可以切换 max_tokens。推理强度默认不传参，支持的模型可选择 none / low / medium / high。

点击「测试当前填写配置」会实际调用所选模型，发送简短测试提示词，可能产生少量费用。测试未保存的配置不会自动覆盖现有配置；保存后再次测试可更新连接状态。已保存与已验证调用分别显示，读取模型列表成功不等于生成成功。模型错误不会自动替换成本地模板。

预设包含 gpt-6.1-sol、gpt-6-astra、gpt-6-luna。当前网络无法读取官方模型文档正文，因此这些 ID 采用 OpenAI Docs 技能随附的模型快照，未声称已验证账号权限或各中转支持情况。模型以服务商列表及真实调用测试为准，可随时输入其他模型 ID。

仍支持 .env 配置：复制 .env.example 为 .env，填写 AI_BASE_URL、AI_API_KEY、AI_MODEL、AI_PROTOCOL、AI_TOKEN_FIELD、AI_REASONING 后重启。页面保存的 ai-config.json 优先于环境变量。AI_CONFIG_PATH 可指定其他服务端配置文件位置。未配置密钥时继续明确标记为本地规则构思。

实现参考用户指定的 pi AI 包在自定义 provider 中分离 baseUrl、认证、模型及协议的方式，并采用可选兼容参数；本站只实现中文写作所需的两种 OpenAI 协议，没有引入其完整代理、工具或 OAuth 系统，也没有读取其他应用的凭据。

参考：
- pi AI：https://github.com/earendil-works/pi/tree/main/packages/ai
- OpenAI 模型目录：https://developers.openai.com/api/docs/models
- OpenAI Responses：https://developers.openai.com/api/reference/resources/responses/methods/create

生成超时为 180 秒。支持解析 Responses output_text 消息和 Chat content 文本 / 文本数组，返回模型 ID 及可用的 token 用量；超时、权限、配额、空正文、截断输出分别明确报错，上游原始错误不直接回传，以免中转回显密钥。去 AI 味模式不使用词语黑名单，按上下文编辑，且不新增“真人经历”。两种协议、密钥隔离、配置持久化、去 AI 味技能加载和请求失败通过模拟服务验证。另已通过本机保存的中转配置实际请求 gpt-6.1-sol，中文去 AI 味示例返回成功：保留功能信息、计划与测试状态、反馈归因和数据缺口。安装包不包含本机模型密钥或配置。

## 中文去 AI 味技能

在写作页选择「去 AI 味」，粘贴原文或公开文章链接后开始编辑。稿纸上也有「去 AI 味」按钮，会先保存当前作品，再把正文转入待编辑输入框；生成结果另存为新版本，可点击「查看原稿」对照，旧版本仍在创作记录中。没有模型配置时会引导连接，不以本地模板冒充改写结果。

技能文件在服务端载入为模型编辑规范，修改后需重启服务。规则参考 [Humanizer-zh](https://github.com/op7418/Humanizer-zh) 并独立整理，重点保留事实、归因、不确定性、作者态度、代码与链接；不是词语黑名单。无需按创作页的目标字数扩写，原稿已经自然的部分可以保留。效果取决于模型与原稿，请逐项核对，不保证通过检测器。

## 数据说明

本机单人模式继续使用浏览器 localStorage。账号模式使用 SQLite 保存用户、会话、微信身份、会员方案、会员期限、AI 调用额度/记录、支付订单、通知幂等标记、审计日志和每位用户独立的数据快照；作品、收藏、稿纸和对话自动同步到当前登录账号。SQLite WAL、外键、支付通知入账事务和在线备份已实现。云端模式需先导出旧作品，再登录新账号导入。

## 部署说明

云端预览部署流程见 [DEPLOYMENT.md](DEPLOYMENT.md)。账号登录默认关闭；部署 Compose 配置会启用账号认证、要求管理员启动密钥、由 Caddy 自动申请 HTTPS。管理员后台在 `/admin`，可管理用户、测试权益、会员套餐及售价、订单和审计记录。用户可通过微信开放平台网站扫码授权登录，将微信绑定现有账号或按设置创建新账号。会员中心读取管理员保存的套餐并生成微信支付 Native 扫码订单；商户配置缺项时不显示可付款入口。微信支付通知需通过签名、证书序列号、APIv3 AEAD 解密、商户/应用/金额校验后以数据库事务一次性发放权益。免费额度默认每月 10 次；会员每月最多由环境变量配置的 300 次，总次数另受套餐支付额度限制。每次 AI 请求先原子预占，成功计费，失败退回。

微信授权和支付代码已通过 RSA 签名、APIv3 通知解密和幂等订单测试；真实授权/收款仍须把相应开放平台应用、微信支付商户号、证书和 APIv3 密钥配置到自己拥有的正式 HTTPS 域名，并先用微信支付沙箱/小额授权测试核实微信商户产品权限和回调可达性。测试期间会员中心默认显示“商户待配置”，不会向用户收钱。自助邮箱注册保持关闭；新微信账号创建由 `WECHAT_ALLOW_REGISTRATION` 单独控制，生产可以关闭新注册、仅让已开账号绑定。当前没有邮箱找回密码、自动续费或自动退款；付款已到账的退款应由授权商户后台受理，并同步处理本站已经发放的会员权益。管理员赠送权益仅用于测试，不代表收费。SQLite 只支持单实例部署；扩容前需迁移 PostgreSQL。海外 VPS 面向中国大陆公开运营前，须先确认域名、微信账号/商户资质和适用的合规要求。

本项目不依赖原站线上服务。原站公开源码单独作为分析材料归档，未嵌入新版运行代码。

## 写作工具栏与 AI 对话（2026-10-31）

写作页新增三组十项工具：写作风格、选题推荐、图片识别、去 AI 味、提升文章质量、追问补充、内容诊断、安全检测、平台规范、头条扣分修复。

- 正文优先作为材料，没有正文时使用创作需求。单次最多 20,000 字；不偷偷截断长稿。
- 本地扫描无需 AI，检查字数、段落、长句、重复、符号、绝对化承诺、联系方式，以及事实来源、医疗财经、版权和导流线索。问题可以点击定位原文。规则只是线索，会存在误报、漏报，不做 AI 作者身份识别。
- “AI 深度分析 / 改进”使用当前选择的真实模型。每项工具有独立任务，问题包含原文短引、原因与操作建议。质量、风格、去 AI 味和头条修复可输出完整改稿；追问补充输出具体问题；选题推荐输出标题和素材方向。
- 平台检查为微信公众号、今日头条、小红书等提供不同人工复核清单。规则维护日期显示在界面，尚未接入官方规则更新。参考分不是官方审核分、真实扣分或 AI 检测率，不保证过审、不保证不扣分。医学、投资、法律等事实和资质仍需要作者核查。
- 改稿可编辑预览。应用时保存原稿和当前正在编辑的稿件，再另建新版本；不会静默覆盖原稿。AI 标注的【待作者补充】需要真实材料补齐。
- 图片识别支持真实上传 PNG / JPEG / WebP，最大 3 MB，服务端校验文件签名；点击识别才会发送给模型。模型需要支持视觉输入。识别结果可复制或加入创作素材。
- AI 对话支持多轮消息、上下文开关、重试、复制和预览为新稿。最多 20 条消息、总消息 30,000 字，附带材料最多 20,000 字。对话、输入草稿和待确认稿件保存在浏览器，刷新恢复，并纳入作品备份。消息与勾选的稿件将发送至已配置服务商。
- API Key 始终由服务端保管，不进入工具响应、浏览器存储或作品备份。

新增接口：`POST /api/tool`（本地扫描 / AI 分析）、`POST /api/image`（图片识别）、`POST /api/chat`（多轮对话），均使用会话令牌；图片仅允许受限 data URL，不请求任意外部图片地址。

本轮验证：16 项自动测试通过，覆盖规则定位、平台清单、敏感引用掩码、JSON 校验、会话校验、Chat / Responses 协议、视觉输入和上下文角色。另以隔离浏览器实际调用当前配置模型，验证质量改稿、原稿保留、对话、图片识别及 390px 布局；测试没有改动日常浏览器里的作品数据。


## 对话工作区与独立工具流程（新版）

写作页顶部可切换“写作 / 对话工作区”。桌面采用会话列表、聊天区、稿件三栏，输入框固定在聊天区底部。没有遮罩弹窗，可以同时读回复、编辑稿件。手机通过“对话 / 稿件”切换，会话列表可展开。

会话支持新建、重命名、切换、多轮上下文、停止等待、失败重试、刷新恢复和导出。新会话使用空稿纸；切换会话会恢复各自稿件。AI 回复只有点击“作为改稿预览”并确认保存后才写入新版本。会话备份可以从“工作室设置 → 导入备份”恢复。长对话只发送最近 18 条、合计最多 30,000 字，界面有说明。

工具在独立侧栏工作，每个工具有自己的输入和后续操作：

| 工具 | 输入与结果 |
| --- | --- |
| 写作风格 | 选择风格，设为默认或实际改写；逐处展示修改说明 |
| 选题推荐 | 填读者和目标；返回标题、角度、提纲与所需素材；选中后进入写作 |

## 链接自动读取与快速清空

粘贴一条公开文章链接后立即启动提取，无需点击“读取链接”。手动输入链接仅延迟 180ms，连续编辑时取消旧请求；同一链接的手动点击和自动触发不会重复读取。输入框右上角“清空文本”只清除主题 / 原文并取消当前提取，保留稿纸正文和创作设置；可通过“撤销清空”恢复上一份输入。清空后焦点留在输入框，可以直接粘贴下一条链接。

后端先尝试直接 HTTP 提取；HTTP 较慢时 450ms 后提前启动浏览器，若直接提取失败则立即启动。两条路径以第一份有效正文为准，取消较慢的一条。复用浏览器进程，但每次建立独立浏览器上下文，60 秒闲置后关闭；使用 HTTP 传输加载网页及脚本，保留脚本运行和每次跳转的地址验证，跳过图片、媒体、字体和样式。等待实际文章正文出现，不把外层元信息当成正文。

同一篇文章的并发任务合并，成功结果内存缓存 5 分钟、最多 32 篇，头条文章的追踪参数不影响命中。清空或编辑导致所有等待者取消时，服务端同步中止提取，不让旧正文回填。失败结果不缓存。

本次本机对同一条头条文章的实测：优化前 14.90 秒，优化后首次 7.36 秒，缓存命中 0.01 秒；标题、3,433 字正文的开头和末尾一致。速度受目标网站与网络影响。22 项自动测试通过，新增覆盖提前启动后备路径、取消慢请求、快速 HTTP 不启动浏览器、并发合并、缓存和多等待者取消；另以真实浏览器键盘粘贴验证即时触发、单次请求、清空与撤销、下一篇输入不受旧响应覆盖及 390px 布局。浏览器功能测试使用隔离的数据存储。

## 后台稳定性与诊断

`npm start` 或“启动网站.cmd”使用守护进程，默认端口 4175，保留 `.env` 和已有 AI/账号配置。`npm run start:direct` 供 Docker 等已有进程管理的环境使用。守护每 10 秒检查 `/api/health`，连续 4 次失败后恢复自己的子进程；一分钟内失败 5 次则停止，避免错误配置造成无限重启。仅在该命令实际运行时提供保护，不负责电脑重启后的自动启动。

运行日志为 `data/service-端口.log`（启动时超过 5 MB 保留上一份）；错误响应附 `requestId`，日志只记录请求路径、状态和耗时，不记录正文、密码或 API Key。前端对令牌过期只恢复一次，不重放权限拒绝或网络结果不明的写操作。模型只对明确的 502/503/521/523 临时错误重试一次，共享原有 180 秒期限；429、认证失败、超时及无效内容不自动重试，避免重复计费。中转商依然可能对失败调用计费。

### 通用文章识别（2026-11-08）
